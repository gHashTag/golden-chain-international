# Literature search — 2026-08-22 — W-INTL-265

The search ran in parallel with the implementation of `research/helper_wire_contract.py`, as required by the loop rule. The contribution is deliberately narrow: a finite representation contract for the already-derived 420-bit coordinate payload and its four storage-padding bits. It is not a security claim.

## Directly checked prior art

- **Maringer and Hiller, “Information Theoretic Analysis of PUF-Based Tamper Protection,” arXiv:2502.03221 (2025-02-05)** — https://arxiv.org/abs/2502.03221. The abstract states finite-blocklength and asymptotic lower bounds under explicit attacker capabilities, plus converse bounds on the number of PUF cells. This is the reason the present control does not turn a packet acceptance fraction into a security margin or a leakage estimate. `[prior art / boundary]`
- **Panja, Jiang, and Safavi-Naini, “Robust and Reusable Fuzzy Extractors for Low-entropy Rate Randomness Sources,” arXiv:2405.04021 (2024-05-07)** — https://arxiv.org/abs/2405.04021. The abstract defines robustness as detectability of helper-data tampering and studies robust/reusable fuzzy extractors with information-theoretic security. This is the closest conceptual warning for a future authenticated framing, not an implementation of this packet. `[prior art / open requirement]`
- **Strieder, Frisch, and Pehl, “Machine Learning of Physical Unclonable Functions using Helper Data: Revealing a Pitfall in the Fuzzy Commitment Scheme,” IACR TCHES 2021(2), 1–36** — https://tches.iacr.org/index.php/TCHES/article/view/8786 and https://doi.org/10.46586/tches.v2021.i2.1-36. The page states that public helper data and knowledge of the code can expose learnable structure, including for BCH and other linear codes. Therefore the measured 4-bit padding boundary and 420-bit payload acceptance are not leakage or robustness evidence. `[threat / boundary]`
- **IACR ePrint 2016/854** — https://eprint.iacr.org/2016/854. The repository's earlier literature record uses this as the rank/security boundary for syndrome constructions. The current packet test preserves that separation: image membership is a finite representation predicate, not a security theorem. `[prior art / boundary]`
- **IACR ePrint 2020/888** — https://eprint.iacr.org/2020/888. The repository's earlier literature record uses this as the public-helper-data leakage/manipulation warning. The present result leaves authenticated helper-data framing and an active-attacker model open. `[threat / boundary]`

## What the search changed

The search did not identify a result that makes this project's exact 53-byte candidate canonical framing a contribution. The honest positioning is a reproducible software control that exposes an implementation boundary: four non-semantic padding bits are rejectable, while the 420-bit coordinate payload is full by construction and payload mutations can remain accepted while changing the expanded helper. A future protocol would need a specified authenticated framing and a threat model; the present module supplies neither.

No categorical novelty, security, leakage, deployment, area, timing, FPGA, G16, or Hub71 claim is made. Catalog references retain 83 formats and HW Tier-E union approximately 49-55/83.
