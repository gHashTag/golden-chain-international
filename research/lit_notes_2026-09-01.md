# Литературный поиск — 2026-09-01 — W-INTL-268

Поиск проведён параллельно с реализацией `research/frame_freshness_control.py`. Задача поиска — проверить, является ли строгая монотонная последовательность вокруг ключевого helper-frame самостоятельным вкладом или обычным anti-replay элементом PUF/fuzzy-extractor протоколов.

## Результат поиска

Целевой academic-поиск по `2025 2026 PUF authentication replay freshness helper data` не нашёл прямо относящейся свежей работы 2025–2026 годов. Ближайшие результаты были протоколами PUF-аутентификации 2023–2024 годов, включая работу “A lightweight PUF-based authentication protocol” (arXiv:2405.13146): https://arxiv.org/abs/2405.13146 . Это не основание для заявления о новизне и не доказательство безопасности данного контроля.

Продолжает действовать найденное в W-INTL-267 prior art: обзор PUF-аутентификации отдельно отмечает replay-угрозу при недостаточной свежести сообщений: https://pmc.ncbi.nlm.nih.gov/articles/PMC11487452/ . Работы по robust fuzzy extractors уже покрывают обнаружение подмены helper-data и key-shift/robustness границу: https://arxiv.org/abs/2405.04021 . Поэтому W-INTL-268 не заявляет protocol/security novelty; он фиксирует конечный тестовый state machine вокруг уже ключевого кадра.

Попытка извлечь свежие страницы этих двух источников через content-fetch в этом тике завершилась timeout; вывод не расширяет утверждения сверх ранее записанных проверок и поисковых аннотаций.

## Что измерено

[measured] `research/frame_freshness_control.py` использует seed 20260901, 64 кадра, 8-байтную последовательность и 16-байтный усечённый HMAC-тег. Для фиксированной тестовой фикстуры приняты 64/64 возрастающих кадров; отвергнуты 64/64 точных повторов, 64/64 валидных кадров с меньшей последовательностью, 64/64 мутаций sequence без нового тега, 64/64 кадров с неправильным ключом и 64/64 усечённых кадров.

[proved] В конечном программном verifier state `last_sequence` обновляется только после проверки тега и канонического внутреннего parser-контракта, а sequence, не превосходящая сохранённую, отвергается.

[open conjecture] Это не deployed anti-replay протокол и не security proof: не измерены rollback-resistant storage, distributed ordering, loss recovery, key management, leakage, active attackers, area/timing, FPGA и G16. Каталог остаётся 83 форматами; HW Tier-E union остаётся примерно 49–55/83. Hub71 Cohort 20: дедлайн 21 августа 2026 уже прошёл, статус подачи не оценивался.
