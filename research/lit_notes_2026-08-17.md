# Literature note — 2026-08-17

## Directly verified prior art

- **Maringer et al., “Analysis of Communication Channels Related to Physical
  Unclonable Functions,” arXiv:2112.02198.** The direct export.arxiv.org XML
  record is https://export.arxiv.org/api/query?id_list=2112.02198 and identifies
  the Varying Binary Symmetric Channel (VBSC), with unequal crossover
  probabilities for PUF response bits and channel-state information at the
  decoder. W-INTL-260 therefore remains a finite-code reproduction/control, not
  a new heterogeneous-channel theorem.
- **Krupp, Gomes De Souza, Nassif, and Wehn, “New Number Formats for FFT IP
  Cores in Optical OFDM Transceivers,” arXiv:2607.17835.** The direct XML record
  is https://export.arxiv.org/api/query?id_list=2607.17835. It couples
  application distributions, custom reduced-precision formats, RTL arithmetic
  units, and post-layout PPA. This is a methodological threat to any broad
  format-plus-hardware selection claim; this loop does not make such a claim.
- **Zhao, “Formally Verified Synthesizable Floating-Point Data Types in ARCH
  HDL,” arXiv:2607.23715.** The direct XML record is
  https://export.arxiv.org/api/query?id_list=2607.23715. It describes one
  source rendered to synthesizable SystemVerilog, SMT-LIB, and Lean with
  correspondence checks. This narrows the formal-semantics versus RTL gap;
  the present experiment is instead about finite BCH decoding under unequal
  bit reliabilities.

## Consequence for this loop

The search did not support a stronger novelty statement. The bounded result in
`research/bch_reliability_decoder.py` is [measured] for BCH(127,57,11), 1,000
deterministic frames per case, and a one-bit reliability-aware Chase list. At
mean BER 0.06, the mild heterogeneous case changes 56 hard-decoder failures to
38, and the split case changes 69 to 39. The homogeneous case is a control
(79 to 69), so the list is not claimed to isolate heterogeneity by itself.

[open conjecture] The experiment does not measure helper-data binding, the cost
of retaining reliability metadata, a larger list, FPGA timing, or an RTL
implementation. The numerical counts are controls for this finite model only.
