## Scope

This repository is the **international edition** of the trust-first computing
work. It is English-first, ASCII-only and free of state rhetoric.

It packages the thesis, GoldenFloat + TRI-27 + Trinity Provenance, as two
things:

- an evidence ledger, where every claim is mapped to an artefact a reviewer can
  open;
- a weakness audit, where every finding carries a falsification path.

The research tree behind it sizes a hardware identity root and checks that
sizing in CI.

It derives from the Russian-language `paper3-rossiya30-troica` edition. That
edition is a directory inside
[`gHashTag/trinity-papers-ru`](https://github.com/gHashTag/trinity-papers-ru),
not a repository of its own.

## Verification

The `hard-rules` workflow runs on every push and pull request. It enforces:

- banned vocabulary;
- ASCII-only text under `paper/`;
- consistency of documents against the ledger;
- figures that reproduce from `research/inputs.py`;
- generated RTL that matches its generators;
- every testbench passing.

Every check has a negative control that is required to fire. `STATUS.md` lists
them all.

Run locally:

```bash
python3 scripts/check_consistency.py
```

```bash
python3 scripts/check_figures_reproduce.py
```

```bash
python3 scripts/check_status_current.py
```

## Hard rules

1. English + ASCII only in public artefacts.
2. No state-rhetoric; world-benefit level primary.
3. Statements about people, ownership, legal form, funding and programme outcomes come from `FACTS.md` only. Anything absent there is "not established". (Until 2026-10-09 this rule named UAE ADGM/DIFC as the primary legal vessel; that plan is withdrawn.)
4. Honest energy multiplier x4-8 (95% CI [3, 10]), never x50-100.
5. Trinity Provenance framed as C2PA-COMPATIBLE verifier, not replacement.
6. Trinity Languages 3-tier (6 LLM + 15 MT + 35 preservation), never "56 LLM".
7. Naive vs honest calculation always paired.
8. Sponsored-research outreach (Stream C) gated on live arXiv ID of phi-paper.
9. No hype words: breakthrough / revolutionary / first-ever / Nobel / world-first / industry-leading. <!-- hard-rules:allow -->
10. Every unproven claim tagged `[Open conjecture]` with falsification path.
